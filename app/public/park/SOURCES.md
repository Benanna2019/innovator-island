# Asset sources

- `park-map.webp`: the original Innovator Island theme-park map, the AWS workshop asset `theme-park-map-large.jpg` (2625x4500). It was served from AWS's workshop CloudFront domain, which no longer resolves. I recovered it from `src/assets/map.jpg` in github.com/ojasnaik/theme-park-app at commit `bdea0604014c261e47f04840a6021c9c83b0b071` (checked 2026-11-24). That repo is licensed MIT-0 and mirrors the AWS sample frontend. I resized it to 1400 wide, cropped away the empty sea at the bottom (final 1400x1720) and converted it to WebP.
- `rides/*.webp`: 16 ride icons generated with AI for this project on 2026-11-24 using Grok Bot image generation. Prompt summary: "16 cute flat-vector theme-park ride icons in a 4x4 grid matching the island map palette (orange, teal, sea blue, green, cream), no text". The grid was split into one file per icon and converted to WebP. The original ride icons were only on the dead CloudFront domain, and I found no vendored copy.
- The header wordmark is our own CSS sign ("Innovator Island" in Fredoka). We do not ship the AWS workshop logo, because it carries AWS Serverless branding.
- AWS names and branding are trademarks of Amazon and are not used.

The original ride and facility map coordinates are kept outside the served assets, in `original/original-positions.csv`. They come from `1-app-deploy/local-app/table.csv` in aws-samples/aws-serverless-workshop-innovator-island (MIT-0). The coordinates are Leaflet CRS.Simple, with lat 0..4500 measured from the bottom and lng 0..2625 measured from the left. Convert with top% = (4500 - lat) / 4500 and left% = lng / 2625. Our map is cropped to 1720 of 2400 rows, so the app's `y` values are top% * 2400 / 1720 of the full-height percentage (and a few ride positions were nudged to avoid overlapping markers).
